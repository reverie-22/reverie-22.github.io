UI Demonstration

Two-step workflow for generating and rendering RIB archives from motion-capture data.

Step 1 — Generate RIB Archives

  1. Create a proxy object, such as a polygon cube.
  2. Select the proxy and run mocapUI();.
  3. Select the proxy shape tab to display the interface.
  4. Browse for the mocap data file.
  5. Ensure there is a RIB_Archive folder in the Maya project directory.
  6. Set an end frame in Maya Render Settings.
  7. Run rman genrib;.

Step 2 — Render the RIB Archives

  1. Hide the proxy object.
  2. From the RenderMan menu, select Archives → Create Node.
  3. Browse for the first archive RIB and set the start/end frame.
  4. Change the numeric extension.
  5. Assign a material through the custom shading group on the transform node.
  6. Render an image and confirm that the baked geometry is correct.
